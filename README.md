# 🎬 Professional Telegram Kino Bot

Aiogram 3.x va PostgreSQL/SQLAlchemy asosida yaratilgan professional Telegram kino bot.

## ✨ Imkoniyatlar

### Foydalanuvchilar uchun:
- 🔍 **2 xil qidirish:**
  - Kategoriyalar bo'yicha
  - Kod orqali (masalan: `105`)
- 📊 Statistika
- ✅ Majburiy obuna tizimi

### Adminlar uchun:
- 📊 **Kengaytirilgan statistika:**
  - Jami/faol/yangi foydalanuvchilar
  - Top kinolar
  - Ko'rishlar statistikasi
  
- 🎬 **Kinolar boshqaruvi:**
  - Kino qo'shish (kod, nom, kategoriya, fayl, sifat, til, yil, tavsif)
  - Kino o'chirish
  - Barcha kinolar ro'yxati
  - Top kinolar
  
- 📁 **Kategoriyalar:**
  - Kategoriya qo'shish
  - Ro'yxat ko'rish
  
- 📺 **Kanallar boshqaruvi:**
  - Majburiy obuna kanali qo'shish
  - Kanallarni o'chirish
  - Faol/nofaol qilish
  
- 📢 **Reklama (Broadcasting):**
  - Barcha foydalanuvchilarga xabar yuborish
  - Matn, rasm, video qo'llab-quvvatlash
  - Yuborish statistikasi
